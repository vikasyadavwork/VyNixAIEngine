# Skybound assets

- `Textures/jet.png`: original generated right-facing aircraft, transparent background.
- `Textures/ocean.png`: original generated top-down ocean texture.

Both were generated for this project on 2026-09-04. The opponent reuses the aircraft with a rotation and orange tint. Game sounds are synthesized in C++ at runtime; no third-party sound recordings or remote assets are required. The application font atlas is rasterized from an installed Windows UI font and is not distributed as a font file.
